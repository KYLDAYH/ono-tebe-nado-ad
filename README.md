# Оно тебе надо

Учебный проект Яндекс Практикума: одностраничный сайт аукциона вещей, в которые никто не верил.

Репозиторий проекта: https://github.com/KYLDAYH/ono-tebe-nado-ad

## Запуск

Откройте `index.html` в браузере. Сборка и установка зависимостей не нужны: изображения и шрифты находятся в проекте и подключены относительными путями.

Для просмотра через локальный сервер выполните в корне проекта:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Откройте <http://127.0.0.1:8000/>. Чтобы остановить сервер, нажмите `Ctrl+C`.

## Реализация

- Семантическая разметка HTML5.
- CSS Grid и Flexbox, классы по БЭМ.
- Локальные шрифты Raleway, SVG-логотипы и иконки.
- Переиспользуемые блоки адреса и оверлея.
- Перенос дополнительных карточек на новую строку.
- Навигация к разделам, ссылки телефона и почты, видимый фокус с клавиатуры.

Ширина страницы — 1100 px, согласно заготовке и макету для ноутбука. Это статическая учебная страница: кнопка «Сделать ставку» прокручивает страницу к лотам; обработка ставок на сервере в задание не входит.

## Файлы

- `index.html` — разметка страницы.
- `styles/global.css` — общие стили из заготовки.
- `styles/style.css` — стили проекта.
- `fonts/` — локальные шрифты и их подключение.
- `images/` — изображения, логотипы и иконки из заготовки.
- `.github/workflows/tests.yml` — автопроверка Яндекс Практикума из учебного репозитория.
